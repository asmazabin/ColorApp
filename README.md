# Color Sorting Application - React + TypeScript + Vite

This test app is for color sorting with basic functionality - Add new color, Move color UP/DOWN, Delete color

Commands to run app,

- sudo npm i (Install all project dependancy)
- sudo npm run dev (Run project)
- sudo npm run test (Run test cases)
- sudo npm run converage (Check test cases coverage)

On the click of Add random color, new color will on top.
